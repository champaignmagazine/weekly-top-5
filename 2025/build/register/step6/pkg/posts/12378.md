- Code Data : Identified math-related code from Stack-V2 , filtered via a small language model to ensure relevance .
- Synthetic Data : Generated QA-style text, code translations (e.g., non-Python → Python), and interleaved text-code blocks .
- Deduplication & Quality Control :
- Applied global deduplication and fastText classifiers trained on seed data (annotated by Llama-3.1-70B) to filter math-relevant documents, achieving 98.8% F1 score on out-of-distribution benchmarks .
